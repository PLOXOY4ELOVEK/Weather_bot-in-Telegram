КАК ПОЛЬЗОВАТЬСЯ:

1. Создай своего тг бота через @BotFather в Telegram

2. Получи от @BotFather токен бота и вставь его в код заместо YOUR_TG_TOKEN

3. Зарегистрируйся в https://openweathermap.org

4. Получи на сайте API токен и вставь его в код заместо YOUR_API_TOKEN

5. Запусти код на своем устройстве или хостинге

6. Бот готов принимать и обрабатывать сообщения
